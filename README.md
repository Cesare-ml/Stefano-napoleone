# Stefano Napoleone — sito ufficiale

Single page statica per **Stefano Napoleone**, dedicata ai percorsi:

- **Radici** — Mappa Numerologica Evolutiva
- **Energia** — Reiki
- **Consapevolezza** — Ritorno al Cuore / Consulenza Evolutiva

## Pubblicazione

Il sito viene distribuito automaticamente su GitHub Pages tramite `.github/workflows/pages.yml` a ogni push su `main`.

## Fotografie

La prima versione usa una direzione grafica astratta e non pubblica immagini di repertorio come se raffigurassero Stefano. Per inserire fotografie autentiche, aggiungere in `assets/` immagini ottimizzate WebP/JPEG e aggiornare le sezioni hero, Reiki, numerologia e colloquio.

Set fotografico consigliato:

1. ritratto verticale di Stefano;
2. sessione Reiki reale;
3. Stefano al lavoro su una mappa numerologica;
4. scena di ascolto durante un colloquio.
